## 黑盒社区 v1.1.0 · 第三方桌面客户端

小黑盒社区（xiaoheihe.cn）的第三方桌面客户端，本次主要修复上游接口变更导致的失效问题。

| --- | --- | --- |
| `Heybox-Desktop-Setup-1.1.0-win-x64.exe` | 78 MB | NSIS 安装包，可选安装目录，会创建开始菜单与桌面快捷方式 |
| `Heybox-Desktop-1.1.0-win-x64-portable.zip` | 110 MB | 免安装绿色版，解压后双击 `黑盒社区.exe` 直接运行 |

> 仅提供 Windows x64 版本。

### 本次修复

- **搜索完全失效** —— `/search/v1/web` 已被上游废弃（恒返回 `status=login`），改用 `/bbs/app/api/general/search/v1`，并补齐 `search_type` / `is_pull_down` / `dw` / `web_version=3.0` 等必要参数。
- **推荐流滚动跳条、漏条** —— 服务端**每页固定 10 条、`limit` 参数完全无效**。原实现按 `limit` 累加 offset，导致跳页。改为按实际返回条数推进，并按 `linkid` 去重。
- **板块帖子数量减半** —— 原来固定传 `limit=10`，实际每页约 20 条，已改为按实际条数推进。
- **「全部社区」空白** —— `/topic/feeds/all` 已 404，改用 `/topic/categories` 的订阅 + 推荐 + 热门三段合并去重。
- **帖子详情显示成 JSON** —— `link.text` 是文本块数组的 JSON 字符串而非纯文本，新增解析逻辑拍平为正文 + 图片。
- **评论区渲染不出来** —— `result.comments` 是 `[{comment:[...]}]` 分组结构，新增递归拍平，楼中楼正常显示。
- **消息页假成功** —— 未登录时接口也返回 `status=ok`，导致误判为「已登录但没消息」，现在正确提示需要登录。
- **风控把自己锁死** —— 早期实现命中 `show_captcha` 就全局熔断，会把推荐流和扫码登录一起禁用。改为**按接口分组冷却**（link / search / user 互不影响）。
- **详情偶发空结果** —— 上游有时返回 `status=ok` 但 `result` 为空（风控降级），现在识别为明确状态并提示，不再误显示「暂无评论」。

### 使用说明

推荐流、板块浏览、社区列表、话题搜索**无需登录**即可使用。
帖子详情 / 评论 / 帖子搜索 / 消息中心需要登录：点侧栏「扫码登录」，用小黑盒 App 扫码确认即可。

> ⚠️ 详情与搜索接口的风控较严。经实测，**官方网页在无痕浏览器里访问帖子页同样会被拦截**，这是上游行为，不是客户端 bug。若已被风控，建议先在浏览器登录 xiaoheihe.cn 并手动完成一次人机验证，再通过「设置 → Cookie」粘贴登录态。
